# papa-site

Публичные страницы PAPA (GitHub Pages): страница-визитка с Телеграм-каналами, политика конфиденциальности и инструкция по удалению данных для приложения Meta «PAPA Voronka».
`links.json` — ссылки-приглашения по источникам (без личных данных). Исходный проект — приватный репозиторий `papa`.

`xojaobod/` — мини-приложение бота @XOJAOBODCITY24BOT (Хўжаобод Сити 24, 27.10.2026): свой стиль (зелёный + золото, значок «24»),
3 языка, погода/воздух (open-meteo), разделы по MASTER_PLAN бота, партнёры, рекламная плашка. Кнопки ведут в бот по t.me/XOJAOBODCITY24BOT?start=…
Время намаза в приложении не показывается — только из бота (время вводит владелец).

`dizayn/` — мини-приложение бота @ozodjamoldizaynbot «OZOD JAMOL Дизайн» (31.10.2026): 3D дизайн, объект → м² → стиль, цена $3/м² считается сразу; заявка уходит в бот (sendData с кнопки клавиатуры или ссылка t.me/ozodjamoldizaynbot?start=d_<объект>_<м²>_<стиль>). Чёрный + красный, Montserrat 700–900.
Фото стилей для «Ҳовли уй» и «Офис» в `dizayn/img/hovli_*`, `ofis_*` — Pexels (бесплатная лицензия Pexels, коммерческое использование разрешено, указание автора не обязательно): ҳовли — 1571459, 3797991, 5998117, 15884799; офис — 416320, 380768, 1648776, 31133776 (https://www.pexels.com/photo/<номер>/).
